## Logo System

### Primary Logo
The primary FAMA.LAB logo features our distinctive "F" mark combined with a subtle lab flask inspiration, symbolizing our commitment to experimentation and discovery.

**Files:**
- `logos/famalab-logo-primary-dark.svg` (Dark background)
- `logos/famalab-logo-secondary-light.svg` (Light background)

### Logo Variations

| Variation | File | Use Case |
|-----------|------|----------|
| Icon Only | `logos/famalab-icon-only.svg` | Favicons, app icons, small spaces |
| Wordmark | `logos/famalab-wordmark.svg` | Headers, documents, merchandise |
| White | `logos/famalab-icon-white.svg` | Light backgrounds |
| Gold | `logos/famalab-icon-gold.svg` | Gold-themed applications |
| Black | `logos/famalab-icon-black.svg` | Black/dark themed applications |

### Clear Space
Maintain minimum clear space around the logo equal to the height of the "F" mark (approximately 20% of the logo width).

### Minimum Size
- Digital: 32px width
- Print: 0.5 inches width

## Iconography

### Style Guidelines
- **Line Weight:** 2px consistent stroke
- **Corner Radius:** 4px (soft corners)
- **Grid:** 24x24px base grid
- **Style:** Minimal, modern, geometric

### Icon Principles
1. Simplicity over complexity
2. Consistent visual weight
3. Rounded corners for friendliness
4. Optical balance

### Custom Icons
The FAMA.LAB icon system includes:
- **F Mark:** The brand's signature element

- **Decorative Dots:** Used as accents and separators

All spacing follows an 8px base unit (4px for fine detail).

| Token | Pixels | Usage |

| `space-1` | 4px | Icon padding, tight spacing |

| `space-3` | 12px | Small gaps |
| `space-4` | 16px | Standard gap |

| `space-6` | 24px | Section padding |
| `space-8` | 32px | Large gaps |
| `space-10` | 40px | Section spacing |
| `space-12` | 48px | Hero padding |
| `space-16` | 64px | Section breaks |

## Logo Usage Rules

### DO ✅
- Use provided SVG files for scalability
- Maintain clear space around the logo
- Use approved color variations
- Scale proportionally
- Use on approved backgrounds only

### DON'T ❌
- Stretch or distort the logo
- Add shadows or effects
- Change colors (except approved variations)
- Rotate the logo
- Place on busy/competing backgrounds
- Use below minimum size
- Add borders or outlines

### Background Approvals

| Logo Variation | Dark (#0a0a0a) | Light (#ffffff) | Gold (#c9a962) | Images |
|----------------|----------------|-----------------|----------------|--------|
| Primary (Dark BG) | ✅ | ❌ | ❌ | ❌ |
| Secondary (Light BG) | ❌ | ✅ | ❌ | ❌ |
| White Icon | ❌ | ✅ | ❌ | ❌* |
| Gold Icon | ❌ | ❌ | ✅ | ❌ |
| Black Icon | ✅ | ✅ | ❌ | ❌ |

*With overlay approval

### Incorrect Usage Examples
1. ❌ Scaling width/height independently
2. ❌ Adding drop shadows
3. ❌ Rotating the logo
4. ❌ Changing to unapproved colors
5. ❌ Placing on busy backgrounds
6. ❌ Stacking elements incorrectly

## File Formats

### Recommended Formats

| Use Case | Format | Reason |
|----------|--------|--------|
| Print | PDF, AI, EPS | Vector quality |
| Web | SVG, PNG | Scalability, compatibility |
| App Icons | SVG, PNG (multiple sizes) | Multiple resolutions |
| Favicon | ICO, SVG | Browser compatibility |

### Export Specifications
- **SVG:** Outlines only, no embedded images
- **PNG:** 2x resolution for Retina displays
- **PDF:** CMYK color space for print
