# 2026-01-30

## Gestor-Clawd Deployment Fixes

**Problema 1: Dockerfile COPY public not found**
- O Next.js em modo standalone não gera pasta `public` separadamente
- Solução: Remover COPY desnecessários para `public/` e `src/`
- O `server.js` standalone já inclui tudo necessário

**Problema 3: Healthcheck falhando - servidor bindando no hostname errado**
- O servidor mostra "Ready in 73ms" mas curl não consegue conectar em localhost:3000
- Causa: Next.js standalone espera `HOSTNAME`, não `HOST`
- Solução: Usar `ENV HOSTNAME=0.0.0.0` no Dockerfile
- Aumentar start-period para 15s
